      How to update

      1. Click Copy update prompt below.
      2. Open Claude Code in your project folder and paste it. Press Enter.
      3. Claude Code pulls the new version, tells you what changed, rebuilds the page and gives you the link. Open it and reload.

      Your roles, grades, profile and logs are not touched. Claude Code stops and asks first if you edited any tracked file.

      Crawl for new roles

      Claude Code does the searching. This page can't run it, so copy the prompt and paste it into Claude Code opened in your project folder. The prompt tells it to only read: nothing is sent, posted or applied. A source that isn't connected is skipped.
