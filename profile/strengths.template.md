# Strengths and gaps (template)

> Copy this file to `profile/strengths.md` and fill it in. `profile/strengths.md` is your own file and is not committed.
> The setup prompt in the tracker's welcome tour interviews you and writes it for you. It feeds the grading profile (`grading/profile.md`) and, later, the market-fit analysis.

## Gaps

- **[Gap]**: [What is missing, and anything adjacent you can say instead.]
